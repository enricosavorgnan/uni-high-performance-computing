# Welcome to HPC tutorials

## Description

A project to collect all HPC tutorials to be run on ORFEO cluster
Each tutorials is written in markdown language and should be self explained.


## Usage
To follow the tutorial you should need an account on ORFEO and access to the computational resources involved in the tutorial.
If special permissions are requested, these should be stated and the beginning.
