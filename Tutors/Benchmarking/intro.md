# Why do a benchmark?

Benchmarking is a crucial aspect in HPC.
The aim of a benchmark is to evaluate the performance of the investigated algorithm, code, or hardware.
This is done to identify bottlenecks, optimize performance, and make informed decisions about hardware and software choices.

!!! note "Benchmark: a definition"
    A ***benchmark*** is a code or a set of codes, often standardized, that is used to evaluate the performance of a system, algorithm, or hardware component under specific conditions.

    Usually benchmarks are designed to stress specific aspect of the system and to be executed several times to get a statistically significant result.


## What can we benchmark?

In this lectures we will focus on two main types of benchmarks, which are:

| **What to benchmark?** | **Description**                                  | **Why is it important?**                                                                                         |
| ---------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| **Infrastructure**     | Hardware components (e.g. CPU, network, storage) | To understand the capabilities and limitations of the used hardware, in order to use it in the best possible way |
| **Software**           | Code                                             | To identify possible bottlenecks and make prevision about the overall execution time in different scenarios      |
